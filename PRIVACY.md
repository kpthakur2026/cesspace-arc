# Privacy Policy — CesSpace ARC

This policy describes the data-handling and privacy practices for CesSpace ARC, including local operations and the private ChatGPT-compatible Model Context Protocol (MCP) integration.

## 1. Local and Operator-Managed Architecture

CesSpace ARC Core is local, operator-managed open-source software.

- **No CesSpace-hosted accounts:** CesSpace ARC does not create, manage, or require CesSpace user accounts, profiles, or identity stores.
- **No telemetry:** CesSpace ARC does not include analytics, tracking beacons, heartbeat signals, telemetry SDKs, or crash-reporting relays.
- **No data harvesting:** CesSpace ARC does not collect prompts, source code, workspace file contents, repository metadata, terminal session history, credentials, or system identifiers for CesSpace analytics or product telemetry.

## 2. Local Audit and Evidence Retention

All audit logs, execution journals, and cryptographic checkpoints generated by CesSpace ARC are stored locally on the operator's machine within the operator-configured audit directory.

- Audit records remain under the operator's exclusive custody and filesystem permissions.
- Secret redaction and argument minimization are enforced by ARC's security kernel before audit records are committed to disk.
- CesSpace has no access to operator audit trails or local cryptographic verification logs.

## 3. Remote MCP and AI Provider Data Flows

When using the private ChatGPT remote MCP integration:

- **Direct transport:** Communication takes place directly between the configured AI client (such as ChatGPT via an operator-established secure tunnel or private connection) and the local ARC MCP endpoint.
- **Request payload necessity:** In order to fulfill AI tool calls, remote MCP requests necessarily transmit tool names, parameters (such as relative file paths or query patterns), and receive tool outputs (such as read file contents or git status).
- **Operator responsibility:** Users are responsible for understanding the data-handling, retention, and privacy policies of their chosen AI provider (such as OpenAI) before connecting ARC to remote or third-party AI interfaces.
- **Access control:** All remote connections must be authenticated using operator-managed token files and secured through trusted tunnel or transport encryption.

## 4. Scope and Future Hosted Services

- This policy accurately reflects the current standalone and private remote MCP architecture of CesSpace ARC.
- No public multi-tenant hosted service, cloud relay SaaS, or marketplace listing currently exists.
- If public hosted infrastructure or multi-tenant services are introduced in the future, an explicit updated privacy policy will be published prior to deployment.
- Unproven certifications or regulatory compliance claims are not made.
