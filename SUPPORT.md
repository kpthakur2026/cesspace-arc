# Support

## Usage and operational questions

For reproducible ARC Core defects, use the repository's structured bug report form.

For documentation problems, use the documentation issue form.

For focused public feature proposals, use the feature request form.

Before opening an issue, review the current stable release documentation and search existing issues for the same problem.

## Security vulnerabilities

Do **not** report suspected vulnerabilities in public issues, discussions, or pull requests.

Follow the private reporting process in [SECURITY.md](SECURITY.md).

## Supported release

The current supported stable release is documented in [SECURITY.md](SECURITY.md) and [PUBLISHER.md](PUBLISHER.md).

Validation-only or unsupported platforms may be discussed publicly, but they should not be represented as supported production environments.

## Scope

Public support covers the open-source CesSpace ARC Core and its published operator documentation.

Private CesSpace infrastructure, customer environments, commercial services, unreleased capabilities, and internal planning are outside the public support scope.

## Response expectations

Public issue response times are not guaranteed. Security reports follow the response expectations documented in [SECURITY.md](SECURITY.md).
